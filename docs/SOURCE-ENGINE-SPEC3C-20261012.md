# 원천 엔진 3단계 보정 2 — 라이브 시험 실행 결과 (지휘통제실 → Codex, 2026-10-12)

3B 보정 뒤 라이브 읽기 시험 실행(쓰기 0)에서 확인된 두 가지. 라이브: 아이카 시트 장기특별이벤트 32줄·신차선출고 1줄 읽음, 원천 판매 가능 32, 이 중 번호 없는 줄 1.
1. 버그: 대여료 열이 빈칸인 기간(예: 60개월 O 열 빈칸)에 «대여료 UNKNOWN 기간»을 만든다 → 레코드 12개가 TERMS_HOLD. SPEC3B 지시대로 «값이 있는 기간만, 빈칸 기간은 만들지 않는다»를 고치고 시험(36/48/60 중 48만 값이 있으면 terms 는 48 하나)을 추가. 이 수정 뒤 이 12건이 정상 레코드가 되어야 한다.
2. 설계 수정: 번호 없는 줄(UID_REQUIRED·번호미배정) 1개 때문에 읽기 전체가 complete=false(PARTIAL)·계획이 SOURCE_INCOMPLETE 로 막힌다. 올바른 동작: 번호미배정 줄은 «그 줄만 보류+번호미배정 집계»이고, 읽기의 완전성은 «시트 범위 전체를 읽었는지(탭·행 범위, 숨김 메타데이터, 429·403·부분 읽기 실패 없음)»로 판정한다. 번호미배정 줄이 있어도 ENROLL·UPDATE·REEXPOSE·명시적 판매불가 하향은 정상 계획하고, «원천에 없어서 하향(SOURCE_ABSENT)»만 생략(그 줄이 기존 차일 수 있으므로) — 계획에 ABSENCE_DOWNGRADE_SKIPPED 사유와 번호미배정 N 를 남기되 blockers 로 막지 마라. 같은 변경이 F05(렌트존 신차 번호 없는 4줄) 에도 적용되게 공통화.
3. 시험: 위 두 가지 합성 시험(번호 없는 줄 1개 + 정상 줄들 → 정상 줄은 계획되고 사라진 차 하향만 0), 기존 시험 전부 통과.
