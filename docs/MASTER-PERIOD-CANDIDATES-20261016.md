# 마스터 생산 기간 확인 요청 — 대표용 한 장 (2026-10-16)

손오공 AI 정제(원문 차명 + 연식으로 마스터 세부모델 기간에 맞춰 한 대씩 선택) 중, **원문이 가리키는 모델과 마스터 기간이 맞지 않아 세부모델을 비워 둔 5대**입니다.
근거는 «원문 연식이 마스터 생산 기간 밖(또는 원문이 가리키는 항목의 시작 연도 앞)»까지입니다. 실제 출시·생산 시기는 이 문서가 단정하지 않으며 **확인 필요**입니다.
마스터는 대표만 바꾸므로 AI 는 고치지 않았고, 해당 칸은 «모델만 확정, 세부모델·트림 비움» 상태입니다. 기간이 확인되면 같은 방식으로 바로 채웁니다.

## 묻는 것 (대표 결정)
1. «더 뉴 K5 하이브리드 DL3» 의 시작 연도 2026- 가 맞는가?
2. «더 뉴 그랜저 IG» (일반·하이브리드) 의 종료 연도 2022 가 맞는가? 맞다면 연식 2023 + IG 원문은 «기간 밖 → 세부모델 비움» 으로 둘지(그 경우 3대는 모델 그랜저만 확정).
3. «코나 하이브리드 SX2» 의 시작 연도 2026- 가 맞는가?
(참고: 1·3 은 하이브리드 항목만 시작 연도가 늦은 같은 패턴 — 같은 계열 하이브리드 항목의 시작 연도를 한꺼번에 점검할지 결정)

## 처리 방식
- 마스터 기간·이름 변경은 기준 한 장대로 대표만(AI 는 이 표에서 마스터를 수정하지 않음).
- 확인 전까지 위 5대는 모델만 쓰고 세부모델·트림은 비워 둡니다(추정 금지). 확인 후 같은 방식(연식 ∈ 기간 하나)으로 채웁니다.
