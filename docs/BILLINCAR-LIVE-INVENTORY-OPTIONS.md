## 1. 지금 빌린카 원천과 수집 현황
- **재고 원천 둘이 있다**: ① F67 «빌린카 프리패스 재고»(빌린카재고 탭, 마지막 수정 10-08 — 정책·재고 원본, Data 상품의 `sheet_source_tab` 이 이 탭을 가리킨다) ② 공통 입력 시트의 «빌린카» 탭(공통 시트 15분 갱신이 읽는다). 공통 시트 쪽 입력 주체(빌린카가 직접 넣는지, F67 에서 옮기는지)는 이번 점검으로 확인하지 못했다 — 확인 필요 1건.
- **수집 현황(실측)**: 판매 중 34대 전부가 최신 완료 공통 시트 run 원문에 있다(편입 34/34). 원본(F67)↔Data 값 대조: 상태·주행거리·옵션·연료·색·분류·배기량·가격·최초등록·기간별 월료·장기보증 100% 일치, 이상은 연식 12(원본 칸이 «2000»), 단기보증 44(정책 보증금 적용으로 추정), 제조사 표기 8(르노→르노코리아, 기준 한 장과 어긋난 규칙 문제), 차명 원문 1.
- **즉시 출고 리스트(xlsx, 10-11 공유)**: 대화방 첨부라 이 담당은 열람하지 못했다. 구조(열·갱신 방식)는 EN1 이 받은 파일에서 확인해야 한다 — 확인 필요 1건.
- 신선도 한계: 우리 쪽 15분 수집은 GitHub 예약 준수율이 낮아(약 4%) «실시간» 수준은 지금 수집 주기와 별개로 보장되지 않는다. 연동 방식과 상관없이 주기 복구가 선행이다.
