# F01 · F86 시트 표시 규격 v1

확정일: 2026-09-21. 사용자 요청으로 탭명·대수·색상·표시 원칙을 통일했다.
기계 판독 정본은 `contracts/f01-f86-sheet-spec.v1.json`이다. 이 문서는 그 규격의 설명이다.
이전의 날짜/대수 없는 탭명 규칙과 별도 오공구독 탭 규칙보다 이 규격이 우선한다.

## 탭명 · 순서 · 색상

| 순서 | 이름 규격 | 색상 | HEX |
|---|---|---|---|
| 1 | MM.DD HH:mm 상품리스트 N대 | 파랑 | #4A86E8 |
| 2 | 손오공상품 N대 | 보라 | #8E7CC3 |
| 3 | 픽업구독 N대 | 청록 | #45818E |
| 4 | 오플구독 N대 | 초록 | #6AA84F |
| 이후 | 공급사명 N대 (F86) | 회색 | #7F8C8D |

- F01/F86 앞 네 탭은 이름 형식·순서·색상을 동일하게 한다.
- 공백만 구분자로 사용한다. 가운데점(·)을 넣지 않는다.
- 대수는 해당 탭 실제 차량번호 행을 기준으로 재계산한다. 중복 키가 있으면 오류로 보고하며 단순 행수를 합격 대수로 쓰지 않는다. 예시 대수를 상수로 고정하지 않는다.
- 상품리스트에만 서울 시각의 월·일·시간을 표시한다. 이는 같은 발행 회차에 명시한 기준 시각이다. 온라인은 고정된 발행 snapshot의 capturedAt, 표시 전용 작업은 명시한 updatedAt을 사용한다. 작업 완료 시각이나 공급사 원천 전체의 최신성을 증명하지 않으며 원천 시각과 snapshot/release는 별도 증거로 관리한다.
- F86 회사 탭은 기존 순서를 유지한다. 동일 차량을 요약 탭과 회사 탭에서 다시 세어 전체 재고에 더하지 않는다.
- 숨김 관리 탭(AI 운영 매뉴얼, AI 인계, 차종사전 등)은 판매 탭명/대수 규격에서 제외하고 보존한다.
- 오공구독 별도 탭은 폐기한다. 중고렌트와 오공구독 상품은 손오공상품 안에서 구분한다. 상품구분 값 오공구독 자체를 없애는 것이 아니다.

## 표 안의 규격

- 고정 열 너비: `차명(원문)` 260px, `옵션(원문)` 360px, `세부트림` 100px. F01/F86에서 해당 헤더가 있는 모든 판매 탭에 동일 적용한다.
- 픽업구독은 설명형 보증금 값을 자르지 않도록 `반납형보증금`과 `인수형보증금`을 각각 180px로 고정한다. 같은 이름이 다른 논리 탭에 있더라도 이 탭별 규격을 임의 확장하지 않는다.
- 긴 원문은 셀 값을 줄이거나 행 높이를 늘리지 않고 기존 CLIP 표시를 유지한다. 링크 원문 열과 금액 열은 화면 전체 폭을 낭비하지 않도록 기존 폭을 보존한다.
- F01은 기존 표 스타일, F86은 기존 레트로/공급사별 스타일을 유지한다. 탭 색 통일을 이유로 본문을 일괄 재도색하지 않는다.
- 헤더 1행 고정, 실제 데이터 전체 폭/높이에 필터를 적용한다. 정렬은 행 전체로 이동한다.
- 차명 축·옵션은 왼쪽, 금액·수치는 오른쪽 정렬을 기본으로 한다. 날짜/상태 등은 기존 의미별 규칙을 보존한다.
- 금액은 원래 숫자와 표시 형식을 보존한다. 기간별 대여료·보증금, 반납형·인수형, 주행거리 조건을 합치거나 대표값으로 축약하지 않는다.
- F86의 금액 영역은 24개월 이상 장기대여료와 장기 보증금/규칙을 보여 준다. 12개월 이하 단기 대여료와 `단기보증`만 삭제하지 않고 숨김으로 보존한다. 기간이 붙지 않은 반납형·인수형 보증금은 장기 보증 정보로 표시한다. F01 단기·보증금 열은 유지한다.
- F86 첫 네 탭 문패는 `MM.DD HH:mm 상품리스트 N대`, `손오공상품 N대`, `픽업구독 N대`, `오플구독 N대`다. 뒤의 렌터카사 탭도 `회사명 N대` 형식이며 중간점이나 별도 시각을 넣지 않는다.
- 배차상태·상품구분·미입력·링크의 색은 기존 의미별 색상 정본을 사용한다. 탭 색과 혼용하지 않는다. 불명확한 값은 0으로 채우지 않는다.
- 구분: 손오공상품=RP012/SON_NO_KONG의 중고렌트+오공구독, 픽업구독=TCAR_EXTERNAL, 오플구독=RP023. 원천/금액/상태 변경은 이 표시 규격만으로 정당화하지 않는다.

## 발행기 적용 및 검증

- 날짜가 상품리스트 이름 앞에 오므로 startsWith('상품리스트') 방식은 사용하지 않는다. 논리 탭 키 또는 확인된 sheetId로 식별한다.
- F01/F86을 같은 규격으로 일괄 처리하고 기존 sheetId를 보존한다. 오공구독 별도 탭을 다시 만들지 않는다.
- 재고 갱신은 검증한 원천과 동일 스냅샷을 사용하고, 통합 전 원본을 보존한다.
- 탭명·순서·색·고유 차량번호 대수·셀 값·필터 범위를 재조회한다. 시트 표기 성공을 원천 정합성 PASS로 바꾸지 않는다.
- 모든 발행 회차는 위 pixelSize를 다시 적용하고 새 readback에서 정확히 일치해야 성공이다. 사용자가 맞춘 규격이 다음 데이터 발행에서 기본 폭으로 되돌아가면 실패로 처리한다.

## 현재 적용 범위

2026-09-21 F01 4개/F86 20개 표시 탭에 이름·색상을 직접 적용했다. F01 손오공상품에는 기존 최신 59대 출력의 셀을 그대로 통합했고 별도 오공구독 탭은 제거했다. F86 단기 관련 11개 열은 값을 보존하며 숨겼다.

운영 Actions의 고정 발행 엔진에는 아직 이 규격을 연결하지 않았다. 저장소 문서/JSON 및 라이브 탭 적용과 자동 발행 영구 반영은 별개이며, 다음 발행 유지 여부를 검증하기 전 자동화 완료로 보고하지 않는다. 문서와 JSON은 현재 로컬 변경이다.
