# 파이프라인 지연표와 손오공(RP012) UID 쓰기 경로 설계 (2026-10-14)

상태: 지연표 = 실측·코드 근거, 5분 감지 작업·즉시 실행 요청 = **설계만(미구현)**, RP012 UID 쓰기 = **설계만**.

## 1. 원천 변경 → 소비처 노출까지 단계별 최대 지연

| 단계 | 현재 주기 | 최대 지연 | 근거 |
|---|---|---|---|
| ① 원천 변경 감지 | 시트·홈피는 감지 없음(회차가 읽을 때 반영), 이안카 상류 synced_at 약 1시간 주기 | 원천별 최대 약 60분 | 정시 전체 회차(:00)가 유일한 읽기 시점 |
| ② 엔진 회차 시작 | 정시 전체 회차 1시간 1회 + 이안카(RP031) 단독 5분 예약(상류 synced_at 변경 시에만 실행) | 전체 60분, RP031 약 5분 | FreePass-Source-Cycle, FreePass-Source-Cycle-RP031 |
| ③ 회차 실행(읽기→계획→쓰기→되읽기) | 전체 회차 약 10분(00:00:04~00:09:49Z 실측), 원천 단독은 1~5분(이안카 읽기 약 5분) | 10분 | B3Q 01:00Z 회차 기록 |
| ④ ERP4 수집(손오공·오토플러스 변동값) | ensure 15분 주기, 풀 회차는 마지막 수집 성공 뒤 75분·시간당 최대 1회 | 약 75~90분 | ensure-erp4-round.ps1 |
| ⑤ ERP5 카탈로그 캐시 | fetchedAt~servedAt 약 60초(커맨드 센터 관측) | 약 60초 | 소비처 읽기 경로 |

합계(현재): 시트·홈피·이안카 최대 약 60+10+1 = **약 71분**, ERP4 경로(손오공) 최대 약 **90분+**. 목표 «지시 후 5분» 과의 차이는 ①②에 있다.

## 2. «지시 후 5분» 구현 상태와 남은 일

| 항목 | 상태 | 남은 일 |
|---|---|---|
| 이안카 5분 단독 예약 | 운영 중(상류 synced_at 변경 시에만 실행) | — |
| 변경 감지 5분 작업(하나의 작업이 원천별 변경 감지 후 순차 실행) | **미구현** | 시트(F05·아이카) modifiedTime, 홈피 목록 해시·사이트맵 상품 수, 상류 synced_at 을 읽어 변경된 원천만 `-Source` 회차 실행하는 래퍼 스크립트 + B3Q 예약 1개 + IgnoreNew |
| 즉시 실행 요청 파일(지시 시 해당 원천 1회) | **미구현** | 요청 디렉터리의 JSON(원천 코드·요청 시각)을 5분 작업이 감지해 해당 원천 1회 실행 후 파일을 처리 완료로 이동 |
| 잠금·API 한도 | 구현됨(링크 잠금, `-Source` 는 인계 금지) | 이안카 429 이력: 이안카는 즉시 실행 대상에서 간격 제한(최소 15분) |

설계 요점: 5분 작업은 «읽기 전용 감지 → 변경 있을 때만 해당 원천 회차». 변경 없음은 UNCHANGED 로 즉시 종료(CPU·API 한도 보호). 즉시 요청은 원천 단위이며 같은 원천의 정기 회차와 잠금으로 직렬화된다.

## 3. RP012 UID 쓰기 경로 설계 (번호 없는 상품 포함)

대표 지시: 엔진 키는 «원천 UID(공급사 코드 + 원천 상품 식별자)», 차량번호는 속성(없어도 편입).

- 키: 번호가 있으면 기존 번호 키 문서와 연결(계획의 번호 브리지), 없으면 `RP012:<손오공 상품 id>` 를 UID 로 쓴다. 문서 ID 인코딩은 `firestore-layout.ts` 규칙을 따른다.
- 쓰기 소유권(이중 쓰기 금지): 1단계 = 엔진은 **번호 없는 상품만** 쓴다. 번호 있는 차량은 ERP4 #574 계열 경로가 먼저 가고, ERP4 가 RP012 변동 쓰기를 멈추는 시점에 엔진이 번호 있는 차량까지 넘겨받는다.
- 구조: 오토플러스 홈피 플러그인과 같다 — 스위치(기본 꺼짐), 관측 병행, 읽기 불완전이면 부재 하향·적용 차단, 편입 상한은 원천 판매 가능 100% 이월, 가격 없음은 INFO_INCOMPLETE 비노출 편입.
- 입력: `sonogong-erp-reader`(버킷 3개, 직렬 250ms) + `classifySonokongRecord`(PICKUP_SUBSCRIPTION/OGONG/USED_RENT). 상태 값은 #572 아티팩트 분포 확정 뒤 매핑표에 반영.
- 필요한 것: B3Q 엔진 환경에 손오공 계정 JSON(대표 손으로 비공개 폴더 배치, 채팅에 비밀 금지).
- 남은 결정: 손오공 상품 id 의 안정성(재사용 여부)을 #572 아티팩트 두 회차 이상으로 확인.
