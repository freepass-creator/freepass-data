## 해석 규칙
- 배기량: 공급사 명목(2,000) vs 정제(1999)는 #494의 의도된 차이 — ±8% 안은 일치로 셌다. 색상(스노우화이트펄→화이트)·제조사 표기는 의도된 정제로 보고 불일치로 세지 않되, 제조사는 «르노·KGM» 확정 규칙 위반만 불일치로 셌다.
- 아이언은 공급사 사이트 실시간 대조를 하지 않았다(`IRON_FETCH_APPROVED` 승인·약관 판정 전). 보존 원문과 정제값의 대조만이다.

## 원인과 조치 후보(적용은 지휘통제실 승인 후)
1. 아이언·일부 시트: 상품의 `원문`이 최초 수집 시점에 멈추고 정제값만 갱신되는 구조(최신 원문 미보존). 새 수집 run 이 최신 원문을 source_runs 에 남기는 것이 근본 해법 — 이번 PR 의 `collect-iron` 이 그 입구.
2. RP023 가격 라벨: 시트에 2만km 구간 열이 없는 8대의 12개월 값을 «12_3만»으로 되돌려야 한다(원본 열 이름 기준). 변환 규칙 확인 필요.
3. 제조사 «르노·KGM» 13대, RP018 연식 6대, RP032 1대: 정제 재계산 대상(원문 기준, 손으로 덮어쓰지 않음).
4. RP023 시트에 없는 판매 중 6대: 공급사 목록에서 내려갔는지 확인 동선 질문.
5. 에스에이·경진카: 원본 시트 연결 기록 보강 후 재대조.

## 추가 확인 (2026-10-12, 접수 2건 추적)
- 위 대조의 «공급사 시트»는 상품에 기록된 개별 공급사 시트(F5x 계열)다. 대표 2026-10-10 결정으로 입력 정본은 F05 공통 시트 공급사 탭이므로, F05 탭 기준 재대조가 필요하다(후속).
- RP023 공급사 시트 43대 중 12대는 상품(products)에 없고(판매중 10·할인판매 1·계약중 1), 판매중 2대는 상품에서 출고불가로 돼 있다. 반대로 상품에서 판매 중인데 시트에 없는 차가 6대다. RP023 상품 문서 70개는 ID 가 `RP023_<차량번호>` 접두형이다(고유 번호 155 = 문서 155, 중복 0).
- 접수 483(오토플러스 팰리세이드)·487(웰릭스 K3)의 차량번호는 F05 공통 시트 전 탭, RP023 공급사 시트, 상품 1,776건, 새 파이프라인 raw 7,941건, 정산원장 차량대장·_상품·취소 탭 어디에도 없다. 두 차 모두 인도 후 공급사 목록에서 내려갔거나 한 번도 목록에 오르지 않은 것으로 보이며, 이력 없이는 구분 불가.
