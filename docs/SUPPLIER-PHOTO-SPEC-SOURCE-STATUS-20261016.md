## 빠진 곳 · 필요한 도구 · 제안 담당(세션)

1. **공통 «공급사 사진 클론 → 드라이브 번호 폴더 → 인입 등록» 규격**: 폴더 `freepasspics/<공급사>/<번호 차종>/`, 800px 압축, 서류 제외, 번호 매칭 — 설계·계획·등록은 `KAKAO-PHOTO-TO-PRODUCT-DESIGN-20261016`(#690). 담당: DATA(현 세션).
2. **손오공**: URL 직접 열림 판정(B3Q 실행) 뒤, 사본이 필요하면 이안카 복사(`iancar-photo-drive-copy`)를 공급사 공통으로 일반화. 담당: 수집 손오공.
3. **아이카**: 목록 페이지(moderentcar.co.kr) 구조 조사 → 번호→상세→사진 일괄 수집 가능 여부 확인(현재 근거 없음). 링크 저장 도구는 main 에 들어와야 DATA 가 계획 모듈과 맞출 수 있다. 담당: 수집 아이카.
4. **오토플러스·아이언**: 사진이 URL 연결뿐이라 드라이브 사본 없음 — 공통 복사 도구로 사본을 만들지 결정 필요(URL 직접 서빙 vs 사본). 담당: 수집 기타.
5. **스타·경진·우리캐피탈·빌린카·렌트존·J&J·퍼시픽**: 원천(사이트·시트 사진 열) 조사부터. 담당: 수집 공급사.
6. **④ 상품 연결 대수**: 공급사별 `photo_original_refs` 보유 문서 수·사본 허용표 값은 B3Q 에서 읽어야 한다(읽기 전용 집계).
