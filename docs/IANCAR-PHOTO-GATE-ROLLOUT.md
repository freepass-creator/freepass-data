# 이안카 사진 ID 게이트 켜기 — 순서와 측정 한 장 (2026-10-12)

목표: ERP5 이안카 상세의 «사진을 불러오지 못했습니다»(47대 중 1대만 200)를 줄이기. 코드(#544)와 배포 환경 전달(이 PR)은 기본 꺼짐이며, 켜는 것은 지휘통제실 승인 사항이다.

## 순서
1. **켜기 전 측정**: `scripts/iancar-photo-gate-measure.mjs --label 켜기전` — 노출 중 이안카 상품 각각의 사진 목록(manifest)과 0번 사진 요청의 200 응답 수(기대: 거의 1대만). 토큰은 환경변수로만, 출력은 개수와 번호 끝 4자리뿐.
2. **변수 설정**: 저장소 변수 `FREEPASS_DATA_IANCAR_PHOTO_ID_GATE_SUPPLIERS=RP031` (형식 `RP###`, 쉼표 구분, 비우면 꺼짐).
3. **배포**: `deploy-read-runtime.yml` 실행. 워크플로가 ① 변수 형식 ② 배포 후 Cloud Run 환경값이 요청과 같은지 ③ consumers 비밀 버전에 `erp5-public-media`(photos 권한·토큰 32자 이상)가 있는지 확인한다(`READ_RUNTIME_PHOTO_ID_GATE_SUPPLIERS`, `READ_RUNTIME_PHOTO_CONSUMER_SECRET_VERIFIED` 기록). 비밀 버전에 소비처가 없으면 비밀 새 버전 추가가 필요하며 이는 «대표 손 한 가지»(비밀 값 관리).
4. **켠 뒤 측정**: 같은 스크립트 `--label 켠뒤`. 합격 기준: 200/200 이 «원천에 차량이 있고 등록 ID 집합이 같은 상품 수»와 같음. 나머지(원천에서 사라진 차 등)는 404 가 정상이며 단발 적용(PHOTO_PENDING)으로 «사진 확인 중» 표시.
5. **되돌리기**: 변수를 비우고 다시 배포하면 즉시 꺼짐(404 복귀). 코드 변경 없음.

## 주의
- 켠 뒤에도 원천(ONE)에서 앨범이 바뀌면(ID 변경) 해당 차는 등록 ID 집합이 달라 404 가 된다 — 자동 수집 재개 후 ID 목록이 함께 갱신돼야 한다.
- 사진 사용 범위 질문(KH·스타스카이·에코) 답이 오면 공급사 단위로 목록에서 빼거나 넣는다.
