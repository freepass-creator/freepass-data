# 상품 구분(product_type) «없음» 원천별 분류 — 한 장 (2026-10-14, DATA)

> 계기: ERP·개발 실측 344대 중 productType «없음» 92대. 코드 기준 원인 분류이며, **원천별 «없음» 대수는 라이브 문서를 읽어야 확정**된다(DATA 는 읽기 경로 없음 → B3Q 스냅샷 필요, 아래 «확인 명령»).

## 엔진이 product_type 을 쓰는 곳(PR 전 / 후)
| 원천 | 전 | 사유 | 후(이 PR) |
|---|---|---|---|
| RP012 손오공 API | 탭→값 기록 | 탭(rent·sub·pick) 고정 어휘 | 변화 없음 |
| RP006 아이언 홈피 | 목록 condition→신차/중고 | 홈피 어댑터가 정함 | 변화 없음 |
| RP004 아이카 월렌트 | `SOURCE_CYCLE_WRITE_MONTHLY_PRODUCT_TYPE=1` 일 때만 «월렌트» | 중앙 어휘 확장 합침 후 켬 | 변화 없음(스위치 그대로) |
| **RP023 오토플러스(시트·홈피)** | **안 씀 → «없음»** | 어댑터가 안 채움 | 정책 고정 «오플구독»(autoplus-policy-invariant 와 동일 어휘). 구분이 빈 노출 문서는 한 번 다시 써서 채움 |
| **F05 공급시트 계열(상품구분 칸 있음)** | **안 씀 → «없음»** | 어댑터가 안 채움(칸은 raw.cells 에 있음) | 칸 값이 중앙 어휘와 **정확히 같을 때만** 채움 |
| **RP004 아이카 장기(구분 칸)** | **안 씀 → «없음»** | 어댑터가 안 채움 | `구분` 칸 값이 중앙 어휘와 정확히 같을 때만 채움(어휘 밖 값은 비움 = 추정 없음) |
| RP031 이안카 | 안 씀 | **원천에 상품 구분 칸 없음**(ONE 목록은 신차/중고 구분 필드를 주지 않음 — 코드·문서에서 확인되지 않음) | 못 채움 → 아래 «결정/요청» |
| 빌린카·스타 등 | 확인 필요 | 엔진 미연결·승격 경로 누락 가능 | 어휘 칸이 있으면 위 F05 규칙이 그대로 적용 |

## 채움 규칙(원칙)
- 원천 **자기 칸** 또는 **고정 정책**만. 이름·가격·차종으로 추정하지 않는다. 어휘(신차렌트·중고렌트·재렌트·신차구독·중고구독·재구독·오공구독·픽업구독·오플구독) 밖이면 비워 «없음» 으로 남긴다.
- **빈 구분만 채운다.** 기존 값은 덮어쓰지 않는다(레거시 분류 보존).
- 월렌트 스위치(`writeMonthlyProductType`)가 켜진 월렌트 행은 기존 규칙이 우선.

## 결정 반영(커맨드 센터 2026-10-14)
1. **이안카(RP031)**: 현상 유지(«없음»). 고정값은 대표 결정 전 금지. 공급사 필드 요청 문안 1줄은 응대가 이안카 방에 전달(아래).
   > 문안: «이안카 ONE 차량 목록·상세 응답에 차량별 상품 구분(신차/중고/재렌트 등 판매 형태) 필드가 있는지, 없다면 추가 가능한지 알려 주세요.»
2. **어휘 밖 변형 표기**: **변환표만 추가, 중앙 어휘는 변경 안 함.** 현재 변환표(`PRODUCT_TYPE_VARIANTS`) = 공백 제거 비교 + «장기렌트»→«재렌트»(수수료 규칙이 이미 쓰는 같은 대응). 모호한 표기(«신차», «중고»)는 넣지 않는다. 실제 값 분포(B3Q 집계) 확인 후 의미가 하나로 정해진 변형만 추가한다.
3. 이미 노출 중인 문서의 «없음»은 다음 정시 회차에서 RP023 만 자동 재기록, F05/아이카는 그 문서가 다른 이유로 다시 쓰일 때 채워진다(구분 단독 재기록 사유는 RP023·월렌트만 둠 — 필요하면 확장 PR).

## 확인 명령(B3Q, 읽기 전용)
products 스냅샷에서 `provider_company_code` 별로 `product_type` 빈 노출 문서 수를 세고, 칸 값 분포(`원문.source.cells` 의 상품구분/구분)를 어휘 밖 값 위주로 집계해 주세요(번호는 끝 4자리만).
