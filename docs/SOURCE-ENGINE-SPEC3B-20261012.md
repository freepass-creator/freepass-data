# 원천 엔진 3단계 보정 — 아이카 실제 시트 형식 (지휘통제실 → Codex, 2026-10-12)

라이브 읽기 시험 실행(쓰기 0)에서 확인한 사실: 아이카 시트 읽기·Firestore 읽기는 이제 동작한다(시트는 gws 경유로 바꿨고 Firestore 필드 경로 백틱 인용 수정함 — src/runtime/source-cycle-runtime.ts, src/infra/source-cycle-firestore.ts 의 이 수정을 되돌리지 말 것). 문제: src/adapters/source-cycle-native.ts 의 아이카 매퍼가 «실제 시트 열 구성»을 몰라서 모든 줄이 차명 빈칸·보증금 UNKNOWN 으로 HOLD(49건) → 기존 노출 15건이 «원천에 없음»으로 하향 계획(DOWNGRADE 15, 편입 0)이 나옴. 이것은 틀린 계획이다.

## 실제 형식 (보이는 탭 «장기특별이벤트»·«신차선출고»·«중고재렌트», 1행 머리글)
열: A 배차상태 · B 구분(재렌트/신차) · C 차량번호 · D 차급 · E 차종분류 · F 트림(= 차명 원문 전체, 예 «쏘렌토 5인승 HEV 1.6 프레스티지 2WD A/T») · G 연료 · H 외장 · I 내장 · J Km · K 월렌트 · L 장기보증 · M 36개월 · N 48개월 · O 60개월 · P 옵션 · Q 최초등록 · R 소비자가격 · S 제조사 · T 배기량 · U 연주행(예 «3만km») · V 대인 · W 대물 · X 자차 · Y 자손.
- 보증금 = L 장기보증 한 칸(기간별 보증금 열은 없음): «무보증» → ZERO, 숫자(예 1,000,000) → KNOWN, 비었거나 해석 불명 → UNKNOWN. 모든 기간 행의 보증금은 이 값. (기존 매퍼가 «N개월 보증금» 열을 찾아 UNKNOWN 으로 만든 것이 버그.)
- 대여료 = M/N/O 에 값이 있는 기간만(36/48/60개월, 원 단위 숫자, 쉼표 제거). 빈칸인 기간은 만들지 않는다(UNKNOWN 으로 채우지 말 것). 주행 = U(연주행) 문자열 그대로(mileage).
- 차명 원문(vehicleText) = E 차종분류 + 공백 + F 트림, 제조사 S, 최초등록 Q, 소비자가격 R, 배기량 T, 연료 G, Km J, 외장·내장 H·I — 원문 칸에 그대로 보존, 차종 4칸은 비움+확인 필요 표식.
- 상태: A «배차문의»=출고협의, «수리중»=상품화중, «배차중»/«배차가능»도 판매 가능으로 둔다(출고불가에 해당하는 값이 시트에 없음, 대표 규칙: 출고불가가 아니면 판매 가능). 판매 불가 판정은 «출고불가» 문자열일 때만.
- «월렌트» 탭(모델명 | 1개월 월 요금, 차량번호 없음) 은 별도 상품군 — 판매 가능 대수·UID·하향 계획에서 제외(관측 전용 집계만).
- 숨김 탭·숨긴 줄 제외, 한 줄 = 한 대, UID = 차량번호(번호 없는 줄은 UID_REQUIRED 로 «번호미배정» 집계).

## 할 일
1. 위 형식으로 aicaNativeCapture/매퍼를 고치고, 합성 시험(위 두 줄 예시를 가짜 값으로 — 차량번호·금액은 합성)을 추가: 무보증 ZERO, 숫자 보증금 KNOWN, 빈 기간 미생성, 차명 합성, 월렌트 제외, 이 보정 뒤 기존 노출 문서와 UID 가 같으면 DOWNGRADE 가 아니라 UPDATE/무변경이 되는 것.
2. 이번 라이브에서 같은 종류의 오류가 났을 다른 원천 매퍼(F05 = 기존 변환기 재사용이라 문제 없을 것, 아이언 홈피 envelope)도 확인만 하고 적으면 된다.
3. 시험 통과 숫자와 변경 파일을 docs/SOURCE-ENGINE-RESULT3B-20261012.md 에. 커밋은 하지 않아도 된다. 네트워크·운영 쓰기 금지, 외부 도구 실패는 건너뜀.
